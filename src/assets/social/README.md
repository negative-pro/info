# Social platform marks

SVG marks sourced from Simple Icons:
https://github.com/simple-icons/simple-icons/tree/develop/icons

Files: youtube.svg, instagram.svg, tiktok.svg, facebook.svg.
The upstream license is preserved in LICENSE.md. Platform names and marks belong to their respective owners.

These assets are rendered as CSS masks. Colors and badge backgrounds are defined in App.css and follow the site's selected theme.
